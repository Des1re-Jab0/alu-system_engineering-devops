# Web Server

Project on transferring files with scp, installing and configuring nginx, redirects, custom 404 pages and a domain name.

## Files

- `0-transfer_file`: transfers a file to a server with scp
- `1-install_nginx_web_server`: installs nginx and serves a page containing Holberton School
- `2-setup_a_domain_name`: domain name pointing to the web-01 server (manzijabo.tech)
- `3-redirection`: adds a 301 redirect from /redirect_me
- `4-not_found_page_404`: adds a custom 404 page
- `5-design_a_beautiful_404_page.html`: custom designed 404 page

## Requirements

- Ubuntu 20.04 LTS
- Scripts 1, 3 and 4 run on the server itself
